# Проверка прогресс-бара

Тестовый файл имеет размер всего 6617 байт, поэтому копирование завершается одним чтением и отображается только как `100%`.

## Проверка через CLI

Для визуальной проверки создайте большой файл и запустите утилиту:

```powershell
$src = Join-Path $env:TEMP "progress-source.bin"
$dst = Join-Path $env:TEMP "progress-copy.bin"

fsutil file createnew $src 1073741824
go run . -from $src -to $dst

Remove-Item $src, $dst
```

## Проверка через тесты

Для просмотра вывода тестов используйте:

```powershell
go test -v
```

Однако визуальную анимацию лучше проверять через CLI: `go test` буферизует вывод тестов.
